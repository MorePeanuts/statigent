# Statigent 文献调研库

本目录服务于硕士论文的两个研究章节：探索性数据分析智能体，以及分析与建模协同驱动的预测建模智能体。研究目标仍以 [课题概览](../docs/overview.md) 为准，实验范围与评价口径仍以 [Benchmark 协议](../docs/benchmark.md) 和 [数据约定](../benchmarks/README.md) 为准。

首轮调研日期：**2026-10-15**。以用户提供的 51 篇论文为种子，保留 42 篇、暂缓 9 篇，补充 15 篇，得到 **57 篇纳入参考文献、9 篇旁支档案、共 66 篇独立笔记**。最新纳入的修订日期为 2026-10-06；这不表示检索覆盖了截至该日的全部研究。

## 如何理解表格

- **R001–R051** 与用户原列表编号一一对应；**R052–R066** 是本轮新增。编号永久保留，不因排序、改题或正式发表而重排。
- **P0** 是直接近邻或当前主基准，优先精读；**P1** 是重要背景/补充；**P2** 是选择性引用。优先级不是论文质量评级，也不是确定要复现的基线名单。
- **暂缓** 的文献退出本轮主线，但保留来源、笔记与原因。后续研究范围变化时可以重新纳入。
- **L1 摘要初读**：核验一手书目信息、摘要或正式发表页，用于筛选和初步归类。**L2 定向阅读**：额外检查指定方法/协议章节。本轮 58 篇 L1、8 篇 L2；没有声称完成逐篇全文精读或本地复现。
- “最早核验年份”与正式发表年、版本修订年分别记录。只列 arXiv 表示本轮采用该来源，**不表示已经确认从未正式发表**。论文载体和文献类型不能一律写为 `[M/OL]`。
- 方法概述及作者实验范围有原文链接；“与项目关系”和“局限”是本次调研分析。作者成绩不能充当本项目的实验结果。

## 后续维护

1. 新文献先核验作者/出版商来源，按 DOI 或 arXiv ID 去重；同一研究的预印本与正式版在同一笔记内维护，避免重复计数。
2. 复制 [模板](template.md)，分配下一个编号；在总表中同步题名、作者、年份、载体、方向、优先级和阅读状态。
3. 深入阅读时记录**具体版本、章节/表号、模型、数据范围、预算、指标、局限**。只读摘要不得升级为完整精读。
4. 记录修改日期及改动缘由。修订版改题、作者变化、实验规模变化时，在笔记保留版本差异，不把多个版本拼成一份不存在的引用。
5. 论文定稿时从选定正式页导出完整书目，再按学校的 GB/T 7714 或其他格式生成；当前笔记末尾是定位用草稿，作者简写不能直接当作完整 BibTeX。

本轮仅建设文献库，不修改方法 Spec、不接入新基线、不运行模型或 Benchmark。文献库以 `main` 的 `1392fc3` 为研究上下文；开发分支后续调整的基线名单应在合并时重新核对。
