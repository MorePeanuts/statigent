# 最小建模协作链路验收

## 验收范围

本次实现 `add-modeling-eda-loop`，验证单目标回归/RMSE 的初始训练、完整双角色 EDA、证据关联后续训练、最终全训练数据拟合、预测交付、独立预测复现和离线评分。它是开发功能验收，不是正式实验，也不检验协作收益或多次运行稳定性。

## 无付费模型检查

- `bun run check`：160 项 TypeScript 测试、34 项 Python 快速测试通过，Biome、Ruff 和 TypeScript 类型检查通过。
- `bun run test:integration`：27 项真实 Docker 集成测试、6 项 Python 内核测试通过。模型响应由可控夹具提供，不调用付费 API。
- 建模整链专项复验：2 项通过，覆盖两次 EDA 的独立内核，以及交付后预测复现、冻结流水线重新拟合、私有标签离线评分、原运行文件哈希不变和数据身份变动拒绝。
- `openspec validate add-modeling-eda-loop --strict`：通过。

整链检查发现并修复了复现剩余毫秒非整数的问题；新增两次 EDA 的测试显式设置了集成测试时限。复现直接读取导出的训练/预测入口，在隔离容器中执行。

## 单次真实模型验收计划

先提交源码、配置和冻结开发清单，再执行一次 `bun run test:smoke:modeling`。固定任务为 DSBench `playground-series-s3e9`，目标 Strength，种子 42；内部训练 3,460 行、内部验证 865 行、外层预测 1,082 行。数据身份与精确划分见 `configs/modeling/dsbench-s3e9-selection.json`。

全部角色使用 `deepseek-flash` profile。父预算为 900 秒、40 次模型尝试、600,000 token 阈值、3 次搜索拟合与 1 次最终拟合；最终阶段预留 180 秒。最多调用一次 EDA，子额度为 300 秒、20 次模型尝试、400,000 token 和 10 次执行，全部计入父预算。

必须实际发生初始训练、完整规划者/执行者 EDA、引用证据的后续训练、最终交付、独立预测复现和冻结交付后的离线评分，才算通过。失败保留记录，不自动追加真实模型运行。
