# agent-workbench Specification

## Purpose

为本机单用户提供 Web 工作台，把数据准备、EDA 任务提交、运行过程观察、取消与结果复核串成一个界面；工作台只调用既有智能体入口、只读既有运行记录，不改变智能体行为与记录协议。

## Requirements

### Requirement: 本机访问边界

工作台服务 SHALL 只监听回环地址，不提供登录，也 MUST NOT 接受非回环来源的请求。浏览器 MUST NOT 接收或提交模型 API 密钥；密钥只从服务端进程环境按所选 profile 的 `api_key_env` 读取。服务端响应、错误信息与日志 MUST NOT 包含密钥值或其他环境变量内容。

#### Scenario: 非回环来源被拒绝
- **WHEN** 请求的来源地址或 Host 不属于回环地址
- **THEN** 服务端拒绝请求，不读取运行记录也不启动运行

#### Scenario: 查看模型列表
- **WHEN** 浏览器请求可用模型 profile
- **THEN** 响应只包含 profile ID、展示名、能力声明及其密钥环境变量是否已设置，不包含密钥值

### Requirement: 工作台输入区

工作台 SHALL 维护专属输入目录，浏览器只能上传文件到该目录、列出和删除其中文件。上传 SHALL 校验文件名（单层、无路径分隔符和隐藏前缀）、允许的扩展名和单文件大小上限，同名冲突 MUST 显式失败而非覆盖。任务 MUST 只能引用输入区内已存在的常规文件，不得引用仓库或宿主其他路径。

#### Scenario: 上传合法 CSV
- **WHEN** 用户上传大小在上限内、名称合法的 CSV
- **THEN** 文件写入输入区并出现在可选文件列表中，附带大小与校验值

#### Scenario: 路径穿越或超限上传
- **WHEN** 文件名含 `..`、路径分隔符、不允许的扩展名，或大小超过上限
- **THEN** 服务端拒绝上传并返回原因，输入区内容不变

#### Scenario: 引用输入区外的文件
- **WHEN** 提交的任务引用不在输入区中的文件或符号链接
- **THEN** 服务端在启动运行前拒绝任务

### Requirement: 任务提交与校验

工作台 SHALL 接收分析目标、约束、模型 profile、组织方式（single 或 planner-executor）、执行后端（persistent-kernel 或 fresh-script）、预算覆盖值和是否要求 Markdown 报告，组装为 EDA 任务后使用与命令行入口相同的规则校验。校验失败 SHALL 返回字段级原因且不创建运行；未填写的预算项 SHALL 使用智能体默认值。

#### Scenario: 合法任务
- **WHEN** 用户提交非空目标、零个或多个输入区文件、已配置的 profile 与合法预算
- **THEN** 服务端分配唯一 run ID，返回该 ID 并开始运行

#### Scenario: 非法预算或未知 profile
- **WHEN** 预算项为负数、非整数或 profile 不存在
- **THEN** 服务端返回校验错误，不分配 run ID、不调用模型

### Requirement: 运行前置条件检查

工作台 SHALL 在启动运行前检查所选 profile 的密钥环境变量是否已设置，以及所选执行后端要求的容器运行时与镜像是否可用。前置条件不满足时 MUST 拒绝启动并说明缺失项，不得启动后再以失败结束来代替检查。

#### Scenario: 密钥未设置
- **WHEN** 所选 profile 的密钥环境变量在服务端进程中不存在
- **THEN** 服务端拒绝启动并提示需要设置的变量名

#### Scenario: 执行镜像不可用
- **WHEN** 容器运行时不可达或所需镜像不存在
- **THEN** 服务端拒绝启动并提示缺少的组件

### Requirement: 隔离的运行进程

每次运行 SHALL 在独立于 Web 服务的进程中执行，使用预分配的 run ID，记录写入工作台运行根目录下以该 ID 命名的目录。工作台 SHALL 限制同时进行的运行数量，超出时拒绝新运行并说明原因。Web 服务的开发热重载 MUST NOT 被视为运行结束。

#### Scenario: 启动运行
- **WHEN** 合法任务通过前置检查
- **THEN** 运行进程开始执行，其运行目录可按 run ID 定位，服务端立即返回而不等待运行结束

#### Scenario: 超过并发上限
- **WHEN** 已有运行数量达到上限时再提交新任务
- **THEN** 服务端拒绝启动并返回当前占用情况

### Requirement: 运行取消

工作台 SHALL 允许用户取消进行中的运行，通过向运行进程发送终止信号触发智能体既有的取消流程，使其以取消终态结束并保留已完成产物。进程在宽限期内未退出时 SHALL 强制结束，并将运行标为中断而非取消成功。

#### Scenario: 正常取消
- **WHEN** 用户取消一个进行中的运行
- **THEN** 运行以 cancelled 终态结束，已产生的轨迹、单元与产物仍可查看

#### Scenario: 取消超时
- **WHEN** 运行进程在宽限期后仍未退出
- **THEN** 服务端强制结束进程，运行显示为中断，并说明终态未经智能体确认

### Requirement: 运行状态的如实呈现

工作台 SHALL 根据运行记录中的终态与运行进程是否存活确定显示状态。记录显示仍在运行但对应进程已不存在（包括服务重启后发现的遗留运行）时 MUST 显示为中断或状态未知，不得显示为进行中或完成；进程以非零状态退出且无终态记录时 SHALL 显示失败并附带可用的诊断摘要。

#### Scenario: 进程意外退出
- **WHEN** 运行进程崩溃且清单未写入终态
- **THEN** 运行显示为中断，并展示进程退出码与错误摘要

#### Scenario: 服务重启后的遗留运行
- **WHEN** 服务重启后列出一个清单仍为 running 但无存活进程的运行
- **THEN** 该运行显示为状态未知或中断，不提供取消操作

### Requirement: 实时轨迹推送

工作台 SHALL 通过服务器推送事件流，按记录顺序增量推送运行轨迹的规范化视图，包括角色与子任务、模型请求与响应及 token 用量、工具校验结果、代码单元与输出、预算剩余与终态。客户端断线重连 SHALL 能从上次已接收位置继续而不重复或遗漏事件。未完整写入的末行 MUST NOT 被推送，直到其写完。

#### Scenario: 观察进行中的运行
- **WHEN** 用户打开进行中运行的详情
- **THEN** 已有事件立即展示，后续新事件在写入后被推送，运行终止后事件流以终态结束

#### Scenario: 断线重连
- **WHEN** 客户端在收到第 N 个事件后断开并携带该位置重连
- **THEN** 服务端从第 N+1 个事件开始推送

#### Scenario: 未知事件类型
- **WHEN** 轨迹中出现工作台未识别的事件类型
- **THEN** 该事件以通用形式展示类型、时间与关联身份，不导致事件流中断

### Requirement: 轨迹内容的角色边界展示

轨迹视图 SHALL 区分规划者与执行者，并按子任务分组展示执行者的代码单元、输出和返回结果。展示内容 MUST 来自运行记录本身，工作台不得生成或改写模型输出、不得把保存了图表表述为模型已看过图表。

#### Scenario: 规划—执行运行
- **WHEN** 查看 planner-executor 组织的运行
- **THEN** 规划者的委派与最终结果、各子任务内执行者的单元与返回分别展示

#### Scenario: 单智能体运行
- **WHEN** 查看 single 组织的运行
- **THEN** 以单一角色展示模型动作与代码单元，不出现空的规划者分组

### Requirement: 结果与产物查看

运行结束后，工作台 SHALL 展示终态及原因、分析结论（含报告 Markdown 及其引用图表）、证据引用、Notebook 或脚本导出状态与下载、token 与执行次数等成本信息。未完成或失败的运行 SHALL 展示已有部分产物并标明不完整，不得显示为成功结论。

#### Scenario: 完成的报告任务
- **WHEN** 打开一个要求报告且已完成的运行
- **THEN** 报告正文渲染显示，引用的图表内嵌展示，可下载 Notebook 与分析结果文件

#### Scenario: 预算耗尽的运行
- **WHEN** 打开一个以 budget_exhausted 结束的运行
- **THEN** 显示终态原因与已有轨迹和产物，结论区域标明无已接受的最终结果

### Requirement: 受限只读产物访问

浏览器 SHALL 只能按 run ID 与运行记录中已登记的产物身份或固定的结果文件名读取内容。服务端 MUST 校验 run ID 格式、拒绝工作台运行根目录之外及符号链接的路径、校验产物完整性，并以安全的内容类型返回；Markdown 中的远程资源与脚本 MUST NOT 被执行或加载。

#### Scenario: 读取已登记产物
- **WHEN** 请求运行记录中已登记且完整性校验通过的图表产物
- **THEN** 服务端以对应图像类型返回内容

#### Scenario: 路径穿越请求
- **WHEN** 请求的 run ID 或产物标识包含路径分隔符、`..` 或指向未登记文件
- **THEN** 服务端拒绝请求且不读取文件

#### Scenario: 报告含外部资源
- **WHEN** 报告 Markdown 含远程图片链接或内嵌 HTML 脚本
- **THEN** 渲染时不加载远程资源、不执行脚本

### Requirement: 历史运行浏览

工作台 SHALL 列出工作台运行根目录中的运行，展示 run ID、开始时间、目标摘要、组织方式、执行后端、模型、显示状态与成本摘要，并按开始时间倒序排列。无法解析的运行目录 SHALL 以错误项列出而不导致整个列表失败。工作台 MUST NOT 列出或读取评测、私有标签或上游答案目录。

#### Scenario: 列出历史运行
- **WHEN** 用户打开运行列表
- **THEN** 工作台运行根目录下的运行按时间倒序显示，损坏的记录显示为错误项

### Requirement: 智能体类型可扩展

工作台 SHALL 以智能体类型区分任务表单、运行入口与结果视图，第一版只提供 EDA 类型。未注册的智能体类型 MUST 被拒绝，而不是回退为 EDA。

#### Scenario: 请求未支持的智能体类型
- **WHEN** 提交的任务声明了未注册的智能体类型
- **THEN** 服务端拒绝任务并说明当前支持的类型

### Requirement: 无付费调用的默认测试

工作台的默认检查 SHALL 使用合成运行记录与可控的运行进程替身验证输入校验、产物访问边界、状态判定、事件增量读取与取消行为，MUST NOT 调用付费模型 API 或依赖完整 Benchmark。真实端到端冒烟 SHALL 通过显式入口运行并携带模型与预算。

#### Scenario: 运行默认检查
- **WHEN** 执行项目默认检查命令
- **THEN** 工作台相关测试在不设置任何模型密钥的情况下通过
