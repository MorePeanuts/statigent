# Spec Delta

## MODIFIED Requirements

### Requirement: 带证据的结构化分析交付

系统 SHALL 要求完成结果包含结论、统计口径或处理说明、局限及当前运行的证据引用，并校验引用对应已记录单元或已保存产物。至少一次实际成功执行及有效证据是完成的必要条件；引用可解析仅表示可追溯，不证明结论语义正确。任务要求报告时，完成结果 MUST 指向本次运行保存的、由模型撰写的 Markdown 报告产物，报告中的图片只能引用本次运行已保存的图片产物。

#### Scenario: 提交有效分析结论
- **WHEN** 模型提交结构合法的结论并引用本次成功单元的统计输出或产物
- **THEN** 系统保存结构化结果和可读报告，关联 Notebook 导出状态，在清理及保存成功后报告任务完成

#### Scenario: 无执行或虚构证据
- **WHEN** 模型未经成功执行就要求完成，或引用不存在、其他运行或未实际执行的证据
- **THEN** 系统拒绝该完成动作并计入动作纠正预算，不报告任务成功

#### Scenario: 报告引用本次图表
- **WHEN** 任务要求报告，模型在工作目录保存报告文件并在完成时指向它，报告以相对路径引用本次保存的两张 PNG
- **THEN** 系统将报告及引用解析为对应产物并记录，任务可以完成

#### Scenario: 报告引用无效图片
- **WHEN** 报告引用不存在、非图片或外部地址的图片，或任务要求报告而未指向有效报告产物
- **THEN** 系统拒绝该完成动作并计入动作纠正预算

#### Scenario: 文本任务保持原行为
- **WHEN** 任务不要求报告
- **THEN** 完成动作不要求报告字段，交付结构与原文本任务一致
